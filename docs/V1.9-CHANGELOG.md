# GEO Intelligence P0 V1.9 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.8，待项目负责人确认

## 变更

- 审计收敛时在完成事务内生成 `metrics-v1` 快照：`metric_snapshots` + `metric_values`，支持重复聚合幂等。
- 回答等权口径计算 Mention Rate、Recommendation Rate、Refusal Rate、Positive Mention Rate、Eligible Response Rate、Mention Frequency；比例使用 95% Wilson 区间，分母为零返回 null。
- 维度至少包含 channel，并额外产出 engineConfigId/provider/modelSelector 切片；跨渠道不合并。
- 分母小于 30 时写入 `metric_quality_flags` 的 `small_sample` 标记。
- `GET /api/v1/audits/{id}/metrics` 支持 `aggregationMethod` 与 `channel` 查询；公开契约沿用 V1.0 已定义的 MetricValue。
