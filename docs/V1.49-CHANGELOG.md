## 跨审计趋势对比（P1）

- 新增 `GET /projects/{id}/audit-trends?limit=`：
  - 按 `finished_at` 升序返回最近的已完成审计；
  - 每个审计取最新可用指标快照（`metrics-v1` 或人工回写的 `metrics-v1h`）；
  - 返回 mention / recommendation / refusal / positive mention / official citation / third-party citation / eligible response 七项；
  - 相邻审计计算 `delta`（百分点差值）。
- 指标聚合：按 channel 维度对 numerator/denominator 加权汇总，避免只看单一渠道。
- 审计详情页新增“跨审计趋势”卡片：最近 4 次审计的核心指标与 delta。
- 契约新增 1 个路径，共 82 Path。

## 边界

- 不提供按问题/竞品/引擎的趋势切片；
- 无统计显著性检验，仅展示差值与区间；
- 同一序列可能混合 `metrics-v1` 与 `metrics-v1h`，响应返回每点版本；
- 无定时监测、快照对比和告警。
