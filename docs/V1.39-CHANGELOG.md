## FEAT-08 人工复核队列

- 自动入队：Judge 评估为不合格或拒答时，写 `review_queue_items`：
  - `INELIGIBLE_ANSWER`（high）；
  - `REFUSAL`（medium）。
- 新增 API：
  - `GET /review-queue`（status/priority/limit）；
  - `POST /review-queue` 手动入队（evaluationId/reasonCode/priority）；
  - `POST /review-queue/{id}/annotations` 提交标签与原因，成功后队列项置 `reviewed`。
- 校验：空 labels/reason 422；非 pending 重复复核 409；不存在 404。
- 管理端新增“复核队列”页面：优先级/原因/问题/结果展示，一致性判定与原因提交。
- 契约新增 GET/POST 队列路径，共 64 Path。

## 实测

- 手动入队一个真实 DeepSeek 评估：`MANUAL_SAMPLE` high；
- 列表返回问题、回答结果与有效性；
- 提交 labels `{decision: agree}` + reason，状态变为 reviewed；
- 重复复核 409，空标签 422；
- 证据：`.run/review-queue-verification.json`。

## 已知边界

- 未实现分派、批量复核、仲裁（adjudications）；
- 未统计机器/人工一致性；
- 自动入队只覆盖不合格与拒答，未覆盖低置信度；
- 答案正文未在队列接口返回（原始内容未内联存储）。
