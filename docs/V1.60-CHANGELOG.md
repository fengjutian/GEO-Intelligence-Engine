# GEO Intelligence P0 V1.60 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.59，待项目负责人确认

## Embedding 默认阈值调整为 0.75

基于 30 对人工标注评估：

- 0.75：Precision 1.0，Recall 0.80，F1 0.889；
- 0.80：Precision 1.0，Recall 0.733，F1 0.846；
- 0.60：F1 0.933，但聚类更粗，存在 1 个误合并。

决策：精确率优先，将 `embedding-v1` 默认阈值从 **0.80 调整为 0.75**。

## 实测

| 项 | 结果 |
|---|---|
| 模型 | qwen3.7-text-embedding |
| 默认阈值 | 0.75 |
| 聚类数 | 9 |
| warning | 无 |
| 证据 | `.run/cluster-default-threshold-verification.json` |

## 变更

- 后端默认阈值 0.80 → 0.75；
- 响应未传 threshold 时返回 0.75；
- 问题空间阈值输入默认值改为 0.75；
- 仍支持显式传入 0.30–0.99。

## 边界

- 30 对样本仍小，0.75 是当前数据下的保守选择；
- 不采用 F1 最优的 0.60，因为聚类过粗且存在误合并；
- 阈值调整不会影响已锁定聚类；
- 未在 CI 中强制评估。
