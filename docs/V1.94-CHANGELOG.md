# GEO Intelligence P0 V1.94 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.93，待项目负责人确认

## 批量转任务

- 新增 `POST /api/v1/projects/{projectId}/findings:batch-tasks`：
  - 按 `rule_code` 归并 open finding，每个规则生成一个任务；
  - 标题固定为 `[RULE] N 条问题待修复`，用于幂等：同项目下存在同名未完成任务时跳过；
  - 默认验收项三条（复测归零 / 覆盖涉及页面 / 无同类回归），可整体覆盖；
  - 返回 `created` / `skipped` 与逐规则明细。
- 实测：134 条 open finding 归并为 7 个任务；重复调用 `created=0, skipped=7`。

## 问题集扩充与功效审计

- 问题集从 4 条扩到 40 条（brand / category / comparison / scenario / decision 五类意图）；
- 发布问题集 v3，创建样本数 3 的测量协议，启动 120 样本审计（40 题 × 3）；
- 该规模下每组约 120 条样本，最小可检测效应约 18 个百分点，显著优于此前 n=4 的 99 个百分点。

## 已知边界

- 批量任务以"规则"为粒度，不按页面拆分；
- 幂等仅比对标题，若手工改过标题会重复创建；
- 120 样本审计耗时较长（约 40 分钟），期间指标不可用；
- 预渲染验证仍缺"可控站点"，未执行。
