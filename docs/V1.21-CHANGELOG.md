# GEO Intelligence P0 V1.21 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.20，待项目负责人确认

## 变更

- 新增租户成员管理：
  - `GET /tenants/{tenantId}/members`（Owner/ProjectAdmin 可读）；
  - `POST /tenants/{tenantId}/invitations`（Owner）创建邀请，返回一次性邀请 Token，数据库只存 SHA-256；
  - `PATCH /tenants/{tenantId}/members/{memberId}`（Owner）调整角色或 active/disabled 状态。
- 路径 tenant 必须与已验证 Token 的租户一致，否则 404；角色输入做白名单校验，非法角色 422。
- 保护最后一名 active Owner：降级或停用返回 409。
- 成员邀请与变更写 `audit_logs`（member.invited / member.updated，含前后值）。
- `NewAuthMiddleware` 增加 OIDC/成员校验分支的 401/403 审计记录；成员接口沿用统一 RBAC 包装。
