# GEO Intelligence P0 V1.14 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.13，待项目负责人确认

## 变更

- 报告生成时按 `priority-v1` 计算开放 Finding 的可解释优先级：impact、confidence、businessImportance、fixCost、risk 五项加权，映射为 P0–P3，并写入 `finding_priorities`。
- 报告新增 `priorities` 章节，每项包含 findingId、ruleCode、severity、priority、score 与分项权重；依赖版本记录 `priorityVersion`。
- CSV 增加 priority 行；PDF 模板增加“优先级建议”章节。
- 管理端报告卡片显示优先级数量并支持直接发布（`POST /reports/{id}:publish`）。
- 未引入新的数据库迁移或公开路径；`finding_priorities` 沿用 V1.0 表结构。
