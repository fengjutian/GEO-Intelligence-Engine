# GEO Intelligence P0 V1.13 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.12，待项目负责人确认

## 变更

- 指标生成时为每个 metric value 写入 `metric_evidence_sets`，保存构成成员（evaluation/response/question/sample ID、回答结果、推荐标签、情感、提及数），单值最多内联 1000 条并标记 truncated。
- 新增 `GET /api/v1/metric-values/{id}/evidence`，按租户返回指标证据成员；`MetricValue` 增加 `id` 字段用于下钻。
- 报告 metrics 章节的指标项包含 metric value id，便于报告消费者回溯。
- 迁移 `000011` 为 `metric_evidence_sets` 增加 `content_json`。
- 管理端指标卡片可点击，加载并展示构成回答的 Judge 标签；关闭后回到指标视图。
