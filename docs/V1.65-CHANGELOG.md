# GEO Intelligence P0 V1.65 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.64，待项目负责人确认

## 高召回模式：0.60 + 强制人工复核

- `embedding-v1` 阈值低于 **0.75** 时，重建响应返回：
  - `reviewRequired: true`；
  - `reviewNote`：提示先人工拆分/合并低置信簇，再发布。
- 默认 0.75 不触发复核提示。
- 问题空间 UI 显示黄色警示条。
- 现有“拆分选中 / 合并”操作即为人工复核手段。

## 实测

| 场景 | 阈值 | reviewRequired | 聚类数 |
|---|---|---|---|
| 高召回 | 0.60 | true | 7 |
| 默认 | 0.75 | false | 9 |

证据：`.run/high-recall-review-verification.json`。

## 策略

- 0.60 不设为默认；
- 需要更高召回时显式传 0.60，并把 `reviewRequired` 视为发布前必须处理的提示；
- 当前只提示，不硬阻断发布；如需强阻断，可在发布接口增加检查。

## 边界

- 未按簇粒度标记“需复核”，只返回整体标志；
- 未统计人工复核耗时；
- 未强制审核人签名；
- 默认 0.75 仍是推荐生产阈值。
