# SPEC-04：网站抓取与内容解析规范

> 版本：V1.0｜状态：已批准｜适用：自有站点及获准公开审计

## 1. 目标与非目标

目标是安全、礼貌、可复现地获取公开网页，生成可追溯的页面正文、结构、链接和技术发现。P0 不绕过登录、付费墙、验证码或反自动化措施，不采集私有网络，不执行下载文件中的代码。

## 2. 抓取授权模式

| 模式 | 要求 | 默认限制 |
|---|---|---|
| `verified_owner` | DNS、文件或管理员验证域名所有权 | 使用项目配置限额 |
| `public_audit` | 管理员确认合法目的与公开可访问性 | 更低页数/速率，不抓取表单和下载资源 |
| `external_evidence` | 仅处理明确引用 URL | 单页获取，不做站点遍历 |

每次 Crawl Run 保存授权模式和策略快照。

## 3. URL 发现顺序

1. 起始 URL。
2. `robots.txt` 声明的 Sitemap。
3. 用户配置的 Sitemap。
4. Sitemap Index 与子 Sitemap。
5. 同域页面内链。
6. 用户明确导入的 URL。

发现不等于允许抓取；每个 URL 在调度前重新执行范围、robots 和安全检查。

## 4. URL 规范化

- 解析相对地址，移除 fragment。
- 主机名转小写并进行 IDNA 规范化。
- 移除默认端口，规范路径中的 `.`、`..` 和重复斜杠。
- 保留可能影响内容的查询参数；已配置跟踪参数可移除。
- 不随意改变查询参数顺序，除非确认语义等价。
- Canonical 仅作为信号，不能在未验证时替代实际 URL。
- 保存原始 URL、规范 URL、最终 URL 和 Canonical URL。

URL 去重基于规范 URL 哈希，同时保留不同原始来源。

## 5. 范围控制

策略包含允许/拒绝的 scheme、host、path、MIME、最大深度、最大页数、单页大小、总字节数和总时长。默认只允许 HTTPS/HTTP，禁止 `file:`、`ftp:`、`data:` 等协议。

子域、跨域和重定向目标默认不在范围；必须显式授权。登出、删除、支付、购物车、管理后台、搜索无限空间等路径进入默认拒绝规则。

## 6. Robots 与礼貌策略

- 每个 host 获取并缓存 `robots.txt`，记录状态、内容和解析器版本。
- 以实际 User-Agent 计算允许规则；P0 默认遵守 robots，无绕过开关。
- robots 不可达时使用保守策略和低速率，并在报告中说明。
- 每 host 令牌桶限流，默认并发 2、最小间隔 1 秒，可按站点策略降低。
- 429/503 尊重 `Retry-After`；连续失败触发 host 熔断。

## 7. SSRF 与网络安全

解析 DNS 后拒绝 loopback、RFC1918、CGNAT、链路本地、组播、保留地址和云元数据地址。每次重定向都重新解析和检查，防止 DNS Rebinding。仅允许标准 Web 端口或显式白名单端口。

Crawler 运行在隔离网络，无权访问数据库和内部管理服务。浏览器禁用不必要权限、下载、摄像头、麦克风和持久化凭据。

## 8. 获取策略

### 8.1 静态获取

先使用 HTTP Client 获取，发送明确 User-Agent 和可联系说明。记录 DNS、连接、TLS、TTFB、总耗时、状态码、Header、内容长度和最终 URL。

限制：Header ≤ 64KB，压缩后响应 ≤ 10MB，解压后 ≤ 50MB，重定向 ≤ 10 跳，连接和总超时分别配置。防止压缩炸弹。

### 8.2 动态渲染

满足以下条件之一时使用 Playwright：正文过少但存在应用根节点、关键内容由脚本注入、配置要求渲染或静态/渲染差异抽样。

渲染采用新的隔离 Context；阻止不必要的媒体和第三方跟踪；最大 20 秒；在 DOM 稳定或超时时结束。保存渲染状态和失败原因，不无限等待 `networkidle`。

## 9. 内容类型

P0 必须支持 HTML/XHTML、XML Sitemap、robots.txt 和纯文本。PDF 可登记链接和元数据，但正文解析作为可选能力。图片、视频、音频只采集元数据，不下载大文件。

MIME 以响应头、文件签名和内容嗅探综合判断。可执行文件、归档文件和未知二进制不解析。

## 10. HTML 解析

解析输出：

- title、meta description、robots、canonical、hreflang。
- H1-H6、正文块、列表、表格、FAQ、代码块。
- 导航、页眉、页脚、侧栏和正文区域分类。
- 链接、anchor、rel、图片 alt、媒体字幕引用。
- JSON-LD、Microdata、RDFa。
- 作者、发布日期、更新时间及其证据位置。

正文提取采用 DOM 结构、文本密度和模板去重混合方法。原始 DOM 与抽取块建立 locator 映射，保证结论可回到证据位置。

## 11. 字符集与语言

字符集优先级：BOM → HTTP Header → HTML meta → 检测器。保存原始字节哈希、最终字符集和是否发生替换字符。语言综合 `lang`、hreflang 与文本检测；冲突生成 finding。

## 12. 内容去重和变更

- 原始哈希：响应解压后的字节 SHA-256。
- DOM 哈希：移除易变节点后的规范 DOM。
- 正文哈希：规范空白后的主要文本。
- 近重复：SimHash/MinHash 仅作为候选，不能覆盖原始内容。

正文哈希未变可复用解析和实体抽取；HTTP 元数据与本次 fetch 仍单独保存。变更记录新增、删除和修改的内容块。

## 13. 结构化数据校验

保存每个结构化数据块原文、位置、解析结果和 Schema 类型。区分：语法错误、缺少推荐字段、与正文冲突、URL 无效和实体引用不一致。不得把存在 Schema 直接报告为 AI 推荐优势。

## 14. 错误分类与重试

| 错误 | 是否重试 | 策略 |
|---|---|---|
| DNS/连接超时 | 是 | 指数退避，最多 3 次 |
| 429/503 | 是 | 遵守 Retry-After，host 限流 |
| 4xx（除 408/429） | 否 | 保存状态并完成 |
| robots 阻断 | 否 | 标记 blocked |
| 超大响应/不支持 MIME | 否 | 标记 policy_blocked |
| 浏览器崩溃 | 是 | 新 Context，最多 2 次 |
| 解析器错误 | 是 | 原始内容已保存时独立重跑解析 |

## 15. 可观测性和验收

监控每 host 请求率、状态分布、阻断率、重试率、字节数、静态/动态差异和解析失败率。

验收要求：

- SSRF 测试集和逐跳重定向测试 100% 通过。
- 同一输入和解析器版本生成确定性结构化输出。
- robots、限流、取消和页数/字节限额可自动验证。
- 任一 finding 可定位到抓取批次、页面版本和 DOM/文本证据。
