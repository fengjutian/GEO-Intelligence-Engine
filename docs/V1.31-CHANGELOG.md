# GEO Intelligence P0 V1.31 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.30，待项目负责人确认

## FEAT-04 合并、撤销与实体页面

- 新增 `POST /entities:merge`：同项目、同类型实体合并；源实体保留为 `merged`，canonical 名称写入目标别名，迁移别名、证据与关系。
- 新增 `POST /entity-merges/{id}:undo`：按合并快照恢复别名、证据与关系，源实体恢复原状态，事件标记 `undone`。
- 新增迁移 `000019`：`entity_merge_events.snapshot_json` 保存可逆引用。
- 新增实体管理页面：
  - 项目切换、类型/状态展示；
  - 详情查看别名、来源证据与关系；
  - 人工确认/拒绝。
- 菜单新增“实体知识”，接入项目级访问控制。
- 契约新增合并/撤销路径，共 57 Path。

## 实测

- `Acme GEO Inc` 合并到 `Acme GEO`：源状态 `merged`，目标别名新增 `Acme GEO Inc`/`Acme Inc`；
- 撤销后源状态恢复 `proposed`，别名回到源实体，目标仅保留原有别名；
- 合并/撤销响应包含非零 `occurredAt`。

## 已知边界

- 合并仅允许同类型实体；跨类型归一需后续规则；
- 合并不物理删除源实体，历史引用仍指向源 ID；
- 实体页面暂不支持合并操作（合并/撤销为 API）；
- Microdata/正文候选抽取仍未实现。
