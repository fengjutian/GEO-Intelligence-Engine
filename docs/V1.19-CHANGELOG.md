# GEO Intelligence P0 V1.19 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.18，待项目负责人确认

## 变更

- 新增 `internal/auth`：HS256 JWT 校验（签名、alg、exp、tenant/sub/role），角色归一化与 P0 权限矩阵。
- API 鉴权中间件支持两种模式：
  - `GEO_AUTH_MODE=dev`（默认）：沿用开发租户/操作者，`GEO_DEV_ROLE` 默认 owner，现有本地流程不受影响。
  - `GEO_AUTH_MODE=jwt`：必须携带 `Authorization: Bearer <JWT>`；校验后把可信 tenant/actor/role 注入请求头。
- `/healthz`、`/readyz`、`/api/v1/version` 与 `/internal/*` 不走用户鉴权；Worker 仍用内部 Token。
- 新增 `GET /api/v1/me` 返回当前租户、用户、角色与认证状态。
- 对关键写操作启用 RBAC：项目编辑/归档/配置发布、抓取启动/控制、审计创建/取消、报告导出、任务创建/编辑/验收/评论；任务 done 与 changes_requested 额外要求 `approve_task`（Owner/ProjectAdmin/Approver）。
- 新增 `GEO_AUTH_MODE`、`GEO_AUTH_SECRET`、`GEO_DEV_ROLE` 配置。
- 注意：当前 JWT 为内部 HS256 方案，尚未接入 Keycloak OIDC；生产替换时保持 Principal 与权限检查接口不变。
