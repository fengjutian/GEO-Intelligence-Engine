## 聚类人工锁定、拆分与合并

- 新增 API：
  - `PATCH /projects/{id}/question-clusters/{clusterId}`：锁定/解锁、指定代表问题；
  - `POST /projects/{id}/question-clusters/{clusterId}/members`：移动问题到目标聚类；
  - `POST /projects/{id}/question-clusters/{clusterId}/split`：拆分选中成员为新聚类；
  - `POST /projects/{id}/question-clusters/{clusterId}/merge`：合并到目标聚类。
- 重建聚类时：
  - 保留所有 `locked=TRUE` 聚类及其成员；
  - 锁定成员不参与重新聚类；
  - 只重建未锁定聚类。
- 手工移动/拆分/合并会将目标聚类标记为锁定，成员标记 `manually_locked`。
- 问题空间 UI 增加锁定、拆分选中、合并到目标聚类操作。
- 契约新增 4 个路径，共 86 Path。

## 实测

| 项 | 结果 |
|---|---|
| 锁定聚类 | true |
| 重建后保留 | 是，成员 4 条不变 |
| 拆分 1 条成员 | 新聚类 1 条，locked=true |
| 合并回原聚类 | 成员恢复 4 条 |
| 证据 | `.run/cluster-management-verification.json` |

## 边界

- 聚类仍为 `jaccard-v1`，同义改写召回有限；
- 拆分/合并不提供操作历史；
- 代表问题可指定，但未提供 UI 下拉；
- 未实现向量/LLM 语义聚类。
