# GEO Intelligence P0 V1.46 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.45，待项目负责人确认

## 项目级成员管理

- 新增 API：
  - `GET /projects/{id}/members`；
  - `POST /projects/{id}/members`（用户必须是 active 租户成员，可设置角色覆盖）；
  - `DELETE /projects/{id}/members/{userId}`。
- 新增/移除写 `audit_logs`（project_member.added/removed）。
- 成员设置页新增“项目成员”区块：选择项目、添加用户 UUID/角色覆盖、查看与移除。
- 与既有 `projectAccess` 规则联动：存在项目成员记录的用户只可访问被授权项目。
- 契约新增 3 个路径，共 77 Path。

## 实测

| 场景 | 结果 |
|---|---|
| 添加 oidc-user-1（Editor） | 201 |
| 项目成员列表 | 1 条，邮箱与角色正确 |
| 非租户用户 | 422 |
| 移除成员 | 204，列表为 0 |

证据：`.run/project-members-verification.json`。

## 边界

- 角色覆盖目前仅记录，不参与细粒度 action 授权；
- 无批量添加、项目成员分页；
- 用户通过 UUID 添加，未接成员选择器。
