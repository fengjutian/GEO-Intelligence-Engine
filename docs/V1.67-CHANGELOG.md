## 竞品问题覆盖对比

- 新增 `GET /projects/{id}/competitor-question-coverage`：
  - 列出 active 竞品；
  - 统计每个竞品在草稿问题中的提及次数；
  - 统计含品牌 + 竞品 + 对比词的比较型问题；
  - 返回未覆盖竞品与无比较问题竞品。
- 问题空间 UI 增加竞品覆盖条，未覆盖竞品标红。

- 只看问题文本，不分析 AI 回答中的竞品份额；
