## 专家复核模板

新增：

- `tests/golden/question-clusters/expert-review.json`
- 106 对问题，`expert` 字段为空，供真实业务专家填写。

`cmd/cluster-eval` 已支持：

- 读取 `expert` 标签；
- 计算专家与裁决标签的 Cohen's κ；
- 输出 `expertAgreement`。

## 状态

真实业务专家尚未提供标注，因此：

- 当前 κ=0.925 仍是双 AI 复核结果；
- 不能宣称已获得真实专家一致性；
- 专家标注回收后重新运行即可得到正式 κ。

## 决策

- 默认阈值保持 **0.75**；
- 0.60 仅作为“高召回 + 强制人工复核”的可选模式，不作为默认；
- 不伪造专家标签。

## 边界

- 权重为业务先验，不是实际流量分布；
- 专家模板尚未回收；
- 未实现多标注者 Fleiss κ；
- 加权评估依赖真实 embedding 额度。
