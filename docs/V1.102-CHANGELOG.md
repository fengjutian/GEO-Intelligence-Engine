## Finding 完整证据链

Finding 现在可以保存并查询一条可复测的完整证据链：

```text
问题 → AI 回答 → 官网页面 → 建议修改 → 优化任务 → 复测审计
```

- 新增 `finding_evidence_chains`，关联问题、回答、页面内容、优化任务和复测审计。
- 保存时校验全部引用属于同一租户和项目，且回答确实对应所选问题。
- 页面型 Finding 未显式传入 `pageContentId` 时，自动使用 Finding 的来源页面。
- 创建优化任务时自动回填证据链的任务节点。
- 复测结果支持 `pending`、`improved`、`unchanged`、`regressed` 和 `inconclusive`。
- 新增 `GET/PUT /api/v1/findings/{findingId}/evidence-chain`，PUT 为幂等更新。

## 当前边界

- 本增量先交付数据模型和 API 纵向切片；管理端可视化编辑器将在后续增量提供。
- `retestOutcome` 是人工或上层统计流程确认的结论，本版本不根据单一指标自动判定改善。
