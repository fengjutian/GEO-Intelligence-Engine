# GEO Intelligence P0 V1.8 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.7，待项目负责人确认

## 变更

- Python Judge 新增 `POST /internal/judge/v1/evaluate`，对回答执行确定性判定：内容有效性（empty/truncated/valid）、回答结果（refusal / no_recommendation / recommendation）、品牌提及与字符偏移、推荐标签、情感、资格。
- Model Worker 在模型响应成功后调用 Judge，把结果随样本完成写入 `evaluation_runs` 与 `answer_evaluations`；合格回答累加 `audits.eligible_count`。
- Judge 不可用时保留模型响应并记录告警，该回答不计入资格指标，不阻断审计收敛。
- 新增 `GEO_JUDGE_URL`（默认 `http://127.0.0.1:8081`）；公开 API 与数据库结构无变化。
