# ADR-006：原生本地开发，Docker 作为可选方案

> 状态：已批准｜决策日期：2026-11-13｜文档版本：V1.1

## 背景

ADR-005 将 Docker Compose 定义为本地开发基线，这会把容器运行时变成所有开发人员的强制依赖。项目要求本地开发、测试和数据库迁移在没有 Docker 的环境中也可完成。

## 决策

1. 默认使用宿主机原生 Go、Node.js 和 Python 进程。
2. MySQL、Redis、对象存储和身份服务可以使用本机安装实例或团队共享开发实例，通过环境变量配置。
3. 数据库迁移由仓库内的 Go 命令 `go run ./cmd/migrate up` 执行。
4. Dockerfile 与 Compose 文件继续维护，但仅用于 CI、隔离测试、快速演示和选择容器部署的环境。
5. 功能实现、测试脚本和验收步骤不得把 Docker 作为唯一执行路径。

## 结果

本决策仅取代 ADR-005 的本地开发部分，不改变 AWS 托管生产基线。README、Makefile 和 CI 必须同时保留原生路径；Docker 路径属于可选适配层。
