## 监测多副本锁与执行失败告警

- `claimDue` 使用事务 + `FOR UPDATE SKIP LOCKED` 领取到期 schedule，并先推进 `next_run_at`；
- 多 API 副本不会重复领取同一 schedule；
- 迁移 `000025_monitoring_alert_unique`：
  - `(schedule_id,audit_id,kind)` 唯一；
  - 执行失败告警使用 `INSERT IGNORE` 去重。
- Runner 每轮检查 `last_audit_id` 对应审计：
  - `failed` / `cancelled` → `audit_execution_failed` 告警。

## 事实核验 UI / 报告
