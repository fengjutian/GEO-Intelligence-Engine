## FEAT-05 问题生成、导入与聚类

- 生成：`POST /projects/{id}/question-generation-runs`
  - 基于冻结知识快照（品牌/产品/竞品/实体）和 `template-v1` 生成草稿问题；
  - 保存 `question_generation_runs`、来源、品牌型/非品牌型、生成依据；
  - 默认中文模板，支持语言参数。
- 导入：`POST /projects/{id}/questions:import`
  - 两阶段：`commit=false` 预览、`commit=true` 提交；
  - 逐行返回 valid/duplicate/error；
  - 阻止公式注入、超长文本、非法类型、重复问题；
  - 上限 1000 行。
- 聚类：`POST /projects/{id}/question-clusters:rebuild`、`GET /questions-clusters`
  - `jaccard-v1` 确定性相似度；
  - 代表问题、成员、相似度写入 `query_clusters` / `cluster_members`。
- 问题模型补充 topic、funnelStage、brandType、source；文本去重使用 NFKC 规范化。
- 问题空间 UI 增加生成、CSV 预览/提交、聚类重建与聚类成员查看。
- 契约新增 4 个路径，共 81 Path。

## 实测

| 场景 | 结果 |
|---|---|
| 基于知识快照生成 | 5 条草稿，0 跳过 |
| CSV 预览 | 4 行：2 有效、2 错误（公式注入、非法类型） |
| CSV 提交 | 2 条入库，错误逐行展示 |
| 重复检测 | 已存在问题标记 duplicate |
| 聚类 | 3 组，算法 `jaccard-v1` |
| 证据 | `.run/question-space-verification.json` |

## 边界

- 生成为模板法，不含 LLM 生成与语义向量；
- 聚类为字符/词 Jaccard，同义改写召回有限；
- 尚无人工锁定聚类、拆分/合并；
- 导入暂只支持 CSV 文本，不支持文件上传。
