# GEO Intelligence P0 V1.51 增量记录

## 语义聚类 semantic-v2

- 新增 `semantic-v2` 聚类算法：
  - GEO 领域同义词归一（AI 搜索/生成式引擎、可见度/可见性、提升/提高、推荐、引用、工具、优化等）；
  - 去除问题填充词（如何、怎么、哪些、what、how 等）；
  - 中文双字词 + 英文词元，按语料 IDF 加权 Jaccard；
  - 保留 `jaccard-v1` 以兼容历史结果。
- `POST /projects/{id}/question-clusters:rebuild?algorithm=semantic-v2|jaccard-v1`。
- 默认使用 `semantic-v2`；问题空间 UI 增加算法选择。
- 锁定聚类与人工成员仍跨重建保留。
- 契约路径总数不变（86），重建接口新增 algorithm 参数。

## 边界

- 同义词表为人工维护，非向量/LLM 语义模型；
- 中文按双字词匹配，长尾改写与跨语言语义仍有限；
- 聚类阈值固定 0.3，未按语料自适应；
- 未引入 embedding 服务或模型调用。
