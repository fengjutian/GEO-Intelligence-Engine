# V1.103 — 可复核 GEO 证据链

本版本把 Finding 升级为“问题—回答—页面—修改—复测”的闭环，并补齐以下能力：

- 候选证据 API：按 Finding 文本相关度返回历史问题与回答，附带关联页面版本。
- 管理端编辑器：选择证据、填写修改目标和复测计划、创建任务并推进状态。
- 不可变证据快照：保存问题、回答及内容哈希、页面及内容哈希、测量协议和基线指标。
- 复测可比性：检查问题版本、指标/裁判/提示词版本、渠道、模型、地区、语言与样本量。
- 自动复测结论：结合 Wilson 置信区间与目标提升量，计算 improved、unchanged、regressed 或 inconclusive。
- 状态机与事件历史：记录证据就绪、计划、实施、待复测、评估和最终结论的每次变化。
- 报告集成：报告快照新增 `evidence_chains` section，Finding 摘要带出证据链状态与复测结论。

## API

- `GET /api/v1/findings/{findingId}/evidence-candidates`
- `GET|PUT /api/v1/findings/{findingId}/evidence-chain`
- `POST /api/v1/findings/{findingId}/evidence-chain/transition`
- `POST /api/v1/findings/{findingId}/evidence-chain/evaluate`

数据库 schema 版本提升至 38。

## 端到端验证

真实审计测试会在 MySQL 中临时创建基线审计（mention rate 0.2）和同协议复测审计（0.6），通过 HTTP 完成证据候选、快照、状态推进和自动结论，并在结束后清理数据：

```powershell
$env:GEO_TEST_DATABASE_DSN=$env:GEO_DATABASE_DSN
go test ./internal/httpapi -run TestEvidenceChainRealAuditE2E -v
pnpm --dir apps/web test -- EvidenceChainEditor.test.tsx
```

未设置 `GEO_TEST_DATABASE_DSN` 时，真实数据库测试会跳过，普通单元测试不依赖本地 MySQL。
