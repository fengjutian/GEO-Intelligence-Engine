## 生成专家代理标注

按要求为 106 对问题生成 `expert` 标注：

- 由 DeepSeek 独立标注（不读取 `same` 裁决标签）；
- 严格二分：同一买家意图 / 不同意图；
- 结果写入 `tests/golden/question-clusters/expert-review.json`；
- 每行标记 `expertSource=deepseek-flash-ai-proxy`。

**重要：这是 AI 专家代理，不是真实业务专家。** 不能用于宣称“真实专家一致性”。

## 专家代理一致性

| 指标 | 值 |
|---|---|
| 样本 | 106 |
| 与裁决标签一致 | 105 |
| 观察一致率 | 0.991 |
| 期望一致率 | 0.500 |
| Cohen's κ | **0.981** |

唯一分歧：

- `What sections are in the audit report?`
- `What does a GEO report include?`

裁决标签为 same=true，专家代理标为 false。两者都可解释，保留分歧。

## 评估影响

使用专家代理标签重跑：

- 非加权 F1 最优仍为 **0.75**（P/R/F1 = 0.887）；
- 加权 F1 最优仍为 **0.75**（0.896）；
- 0.60 加权 F1 0.860，仍低于 0.75；
- 默认阈值不变。

## 结论

- AI 专家代理与裁决标签高度一致，κ=0.981；
- 该结果只能说明“模型与模型/裁决一致”，不能替代真实业务专家；
- 真实专家回收后，覆盖 `expert` 字段并重跑 `cmd/cluster-eval` 即可得到正式 κ。

## 证据

- 专家代理标注：`tests/golden/question-clusters/expert-review.json`
- 评估：`.run/cluster-eval-expert.json`

## 边界

- 专家代理由 LLM 生成，存在自洽偏差；
- 单一模型、单次生成，未做重复采样；
- 真实专家标注仍未获得；
- 106 对样本仍小。
