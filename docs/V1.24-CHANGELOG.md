# GEO Intelligence P0 V1.24 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.23，待项目负责人确认

## 变更

- 后端新增公开 `GET /api/v1/auth-config`，返回认证模式、OIDC issuer/clientId/audience/scope；新增 `GEO_OIDC_CLIENT_ID` 配置。
- Web 新增登录门禁 [AuthGate](../apps/web/src/features/auth/AuthGate.tsx)：
  - OIDC 模式使用 Keycloak 授权码 + PKCE（S256）；
  - 回调校验 state，Token 存于 sessionStorage；
  - 启动时静默刷新，30 秒检查即将过期 Token；
  - API 401 时先尝试 refresh 并重试一次，失败才清除会话并回到登录页；
  - 支持 Keycloak 登出（id_token_hint + post_logout_redirect_uri）；
  - dev 模式完全兼容，不显示登录页。
- 全局 fetch 包装自动附加 Bearer Token，无需改动既有业务请求。
- 新增 12 个 Web 单测（PKCE、回调交换、state 校验、刷新失败、AuthGate 状态）与 Go auth-config 测试。
- 已知边界：真实 Keycloak Realm 尚未提供；Token 存于 sessionStorage（XSS 风险由 CSP 与前端审计控制）；尚无静默 SSO 会话检测。
