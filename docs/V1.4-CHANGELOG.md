# GEO Intelligence P0 V1.4 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.3，待项目负责人确认

## 变更

- 新增 FEAT-06 审计编排接口：问题集版本发布、问题集/版本查询、测量协议创建与发布、审计估算、审计创建、审计查询、取消与样本查询。
- 新增 `GET/POST /api/v1/engine-configs`，引擎配置只返回 provider、channel、region、status，不回显凭据引用。
- 审计创建使用 `Idempotency-Key`，`audits.request_hash` 保存请求摘要（迁移 `000007`）；同键不同请求返回 409。
- 采样键按审计作用域生成，重复审计同一协议不会产生主键冲突；单次展开上限 5000 个样本。
- 协议发布时冻结品牌知识、问题集版本和引擎配置，审计只读取快照。
