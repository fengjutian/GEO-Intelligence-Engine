# GEO Intelligence P0 V1.17 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.16，待项目负责人确认

## 变更

- 验收项可更新：`PATCH /optimization-tasks/{taskId}/acceptance-items/{itemId}` 支持 pending/done，使用 `If-Match` 乐观锁，版本递增并写 `acceptance_updated` 事件；终态任务禁止修改。
- 任务评论：`POST /optimization-tasks/{taskId}/comments` 写入 `task_comments`（迁移 `000017`），同时追加 comment 事件。
- 新增 `GET /optimization-tasks/{taskId}/events` 返回完整事件时间线；任务详情包含验收项、评论与事件。
- 管理端新增任务看板：任务列表、状态筛选、验收项勾选、评论、状态转换按钮（要求修改/取消需填写原因）与事件时间线。
- 契约新增验收项、评论、事件路径，共 50 Path。
