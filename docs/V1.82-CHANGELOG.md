## 边界

- v2 草稿通过 SQL 复制构造，产品尚无“从已发布版本克隆草稿”API；
- Diff 按文本匹配，重命名视为删除+新增；
- 竞品联动按名称小写精确匹配，未接别名；
- 品牌份额来自最近一次含份额指标的审计，不是跨审计均值；
- 报告 PDF 仍保留原始指标/份额/事实章节，篇幅更长。
