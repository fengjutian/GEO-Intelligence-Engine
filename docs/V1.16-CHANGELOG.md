# GEO Intelligence P0 V1.16 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.15，待项目负责人确认

## 变更

- 新增 FEAT-12 优化任务：`POST /findings/{id}/optimization-tasks` 从 Finding 创建任务，复制来源版本、优先级（继承 `finding_priorities`，否则按严重度映射）、验收项并写 `task_evidence_links`。
- 严格状态机：`todo → in_progress → in_review → done`，支持 `changes_requested`、`cancelled`；非法转换返回 409，`changes_requested`/`cancelled` 必须填写原因。
- `POST /optimization-tasks/{id}:transition` 使用 `If-Match` 版本做乐观锁，状态与 `task_events` 在同一事务提交，并写 Outbox 通知事件。
- 新增 `GET /optimization-tasks`（按项目/状态筛选）与 `GET /optimization-tasks/{id}`（含验收项与完整事件时间线）。
- 管理端报告优先级列表新增“创建任务”，创建后显示任务状态。
- 契约新增任务列表/详情路径；沿用 V1.0 的 `optimization_tasks`、`task_events`、`task_acceptance_items`、`task_evidence_links` 表，无迁移。
