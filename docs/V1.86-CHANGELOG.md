# GEO Intelligence P0 V1.86 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.85，待项目负责人确认

## AI 爬虫日志分析

- 新增 `POST /projects/{id}/bot-logs`（批量导入，单次 ≤1000 条）与 `GET /projects/{id}/bot-logs/summary?days=`。
- 按 UA 归类 GPTBot / OAI-SearchBot / ChatGPT-User / ClaudeBot / Anthropic / PerplexityBot / Google-Extended / Bytespider / YisouSpider / CCBot 等，并标记 `isAIBot`。
- 汇总返回每个 bot 的命中数、覆盖页面数、最后访问时间与 AI 总命中数。

## 外部信源提及

- 新增 `POST /projects/{id}/source-mentions` 与 `GET /projects/{id}/source-mentions`、`/summary`。
- 来源类型归一为 review / media / wiki / forum / vendor / other，情绪归一为 positive / neutral / negative。
- 汇总按来源类型给出条数与正负向计数。

## 优化执行闭环（MVP）

- 新增 `POST /projects/{id}/content-drafts`，支持三种产物：
  - `jsonld`：Organization + Product 的 Schema.org 结构化数据；
  - `llms_txt`：基于已抓取页面生成的 llms.txt 索引；
  - `meta`：canonical / title / description / og:site_name 建议。
- 状态机 `draft → approved → published`（或 `discarded`），非法流转返回 409。
- `GET /projects/{id}/content-drafts/{draftId}/diff?against=` 返回字段级差异，用于审批。
- 发布是"记录 + 版本递增"，不写回第三方站点。

## 实验与因果验证（MVP）

- 新增 `/projects/{id}/experiments` 的创建、列表、详情、`/attach`、`/evaluate`。
- 冻结假设与指标；绑定基线与对照审计后执行两比例 z 检验，输出 uplift、z、p、是否显著。
- 结论状态：`effective` / `negative` / `no_significant_change` / `insufficient_data`。
- 样本量保护：任一组分母 < 30 直接判 `insufficient_data`，避免小样本宣布胜利。

## llms.txt 检测

- 新增 `GET /projects/{id}/llms-txt`：8 秒超时、不跟随重定向、上限 512KB。
- 拒绝非 HTTP(S) 与 loopback / 私有 / link-local / `.local` / `.internal` 主机。
- 返回 found、HTTP 状态、字节数、行数、是否引用 sitemap 与前 400 字符预览。

## 已知边界

- Microdata 解析在 `parseStructuredData` 中已支持（本轮核对确认，未新增代码）。
- 外部信源为**导入式**，未实现自动发现/爬取。
- 语义事实核验未落地：需要 LLM 或 embedding 交叉验证，现有 fact-check 仍依赖页面正文。
- 渠道仍只有 model_api；search_api / consumer_app_capture 需要真实账号与适配器。
- 草稿"发布"只更新系统内状态，不写回客户站点或 CMS。
