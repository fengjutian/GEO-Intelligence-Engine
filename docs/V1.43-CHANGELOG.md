# GEO Intelligence P0 V1.43 增量记录

## 服务账号与 API Token

- 新增 `service_accounts` / `api_tokens` API：
  - `POST/GET /service-accounts`；
  - `POST/GET /api-tokens`；
  - `DELETE /api-tokens/{id}` 撤销。
- Token 明文仅在创建时返回一次，数据库只存 SHA-256；支持过期与撤销。
- 鉴权中间件接受 `Authorization: Bearer geo_...`：
  - 校验 token 哈希、过期、撤销，并更新 `last_used_at`；
  - 按 scopes 映射角色：`admin/manage` → ProjectAdmin，`write/run_audit/manage_crawl` → Analyst，否则 Viewer；
  - 租户与 principal 来自 token 记录，不信任请求头。
- 权限：服务账号与 Token 管理仅 Owner（`manage_keys`）。
- 契约新增 5 个路径，共 70 Path。

## 实测

| 场景 | 结果 |
|---|---|
| 创建服务账号 + read token | 成功，前缀 `geo_`，长度 47 |
| read token `/me` | viewer |
| read token 创建项目 | 403 |
| write token `/me` | analyst |
| write token 创建项目 | 201 |
| 撤销 read token 后访问 | 401 |
| Token 列表 | 2 条，无明文 |
| 证据 | `.run/service-account-verification.json` |

## 已知边界

- Scope 到角色的映射较粗，未做逐 action 授权；
- 无服务账号/Token 管理 UI；
- Token 仅支持 Bearer，无 IP/来源限制；
- 真实 Keycloak Realm 仍未接。
