# GEO Intelligence P0 V1.7 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.6，待项目负责人确认

## 变更

- Model Gateway 增加按供应商的平滑 RPM 令牌桶和并发上限，配置项为 `GEO_MODEL_RPM`（默认 60）与 `GEO_MODEL_MAX_CONCURRENCY`（默认 4）。
- 供应商非 2xx 响应返回结构化错误，携带 HTTP 状态与 `Retry-After`；408/429/5xx 和网络错误可重试，认证、参数与政策错误不重试。
- Model Worker 对可重试错误最多尝试 3 次，使用 250ms/500ms 退避并优先遵守 `Retry-After`，单次等待上限 10 秒。
- 公开 API 与数据库结构无变化。
