# GEO Intelligence P0 V1.30 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.29，待项目负责人确认

## FEAT-04 第一阶段：JSON-LD 实体抽取

- 抓取器新增 JSON-LD 解析：从 `script[type="application/ld+json"]` 提取对象/数组，最多 20 条，随 Completion 上报；解析失败静默跳过。
- 新增迁移 `000018`：`structured_data_items.content_json` 保存原始 JSON-LD，支持后续重抽取。
- 新增 `internal/entities`：
  - 支持 Organization、Brand、Product、SoftwareApplication（含 Corporation/LocalBusiness 归一）；
  - 抽取名称、`alternateName` 别名、`brand`/`manufacturer`/`parentOrganization` 关系；
  - 每个实体写 `entity_evidence`（来源 content、quote、locator、extractorVersion=`jsonld-v1`）；
  - 重复 name/type 合并别名与关系，实体按项目+类型+规范化名称幂等 upsert。
- 新增 API：
  - `GET /projects/{id}/entities`（类型/状态筛选）；
  - `GET /entities/{id}`（别名、证据、关系）；
  - `PATCH /entities/{id}`（proposed/confirmed/rejected，人工确认保留）。
- 契约新增 3 个路径，共 55 Path；无 UI。

## 实测

- 通过内部 Completion 注入 Organization + Brand + Product 的 JSON-LD；
- 抽取 3 个实体、2 条关系、1 个别名、1 条证据；
- 人工确认 Organization 成功，抓取 Run `succeeded`；
- 证据：`.run/entity-verification.json`。

## 已知边界

- 仅 JSON-LD，不含 Microdata/正文候选；
- 合并/撤销 API 与实体 UI 未实现；
- 抽取在抓取事务内同步执行，超大数据需异步化。
