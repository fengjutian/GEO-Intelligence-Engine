# GEO Intelligence P0 V1.87 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.86，待项目负责人确认

## 语义事实核验（跨源）

补齐此前"只能在同一页正文里自证"的缺口。新链路把**模型回答里的断言**与**品牌页面 + 第三方信源**做检索 + 裁决。

- 新增 `POST /audits/{auditId}/semantic-checks`、`GET /audits/{auditId}/semantic-checks`、`GET /projects/{projectId}/semantic-checks?status=`。
- 断言抽取：
  - 中英文句末切分，过滤 Markdown 表格行与无实义片段；
  - 单次最多 8 条，去重。
- 证据池：
  - 品牌页面正文（最近 20 页，每段 ≤1200 字）；
  - 导入的第三方提及（标题 + 摘要，≤400 字）。
- 检索：
  - 配置了 `GEO_EMBEDDING_*` 时用 embedding 余弦；
  - 未配置时退化为中英混合 token 的 Jaccard 重叠。
- 裁决：
  - 最高分低于 0.35 直接判 `unknown`，**不调用模型**；
  - 否则把前 3 段证据交给 `deepseek-flash`，要求仅依据证据输出 `supported|unsupported|unknown` + 置信度 + 原文引用；
  - 置信度裁剪到 0..1，非 JSON 输出回落为 `unknown`。
- 结果落库 `semantic_check_runs` / `semantic_checks`，保留相似度与证据来源（`brand_page` / `third_party`）。

## 实测

| 场景 | 结果 |
|---|---|
| 飞书审计 4 条回答 | 抽取 8 条断言，模型 `deepseek-flash`，写入 8 条结果 |
| 证据来源分布 | `third_party` 18 条 / `brand_page` 6 条（累计 3 次运行） |
| 判定分布 | 24/24 `unknown` |
| 检索相似度 | 0.41–0.79，均越过 0.35 阈值，说明是裁决保守而非召回不足 |
| 未知即正确 | 抽取到的多是"优先试用飞书""建议先小范围试用"这类**建议**，保守核验不应把它标成 supported |

## 测试

- `supported` / `unsupported` / 非 JSON 回落 / 置信度裁剪四条分支用假 ChatClient 覆盖（`internal/semantic/judge_test.go`）。
- 断言抽取、分词、Jaccard、排序、阈值、余弦另有 7 个用例。

## 已知边界

- 只核验**模型回答**中的断言，未覆盖页面自身断言与外部文章；
- 未做跨语言证据对齐（中文断言 + 英文证据时依赖 embedding）；
- 一次运行最多 8 条断言、最多 8 次模型调用，未做预算账户接入；
- 证据池依赖已抓取页面与已导入提及：没有抓取和提及导入的项目会返回 `NO_EVIDENCE_TO_VERIFY`。
