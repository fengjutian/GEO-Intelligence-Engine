## 4. 冻结后的变更规则

1. PRD、SPEC 或 FEAT 的行为变化至少升级到 V1.1。
2. 不兼容 API 变更创建 `/api/v2` 或按兼容策略发布新字段，禁止复用字段改变语义。
3. 数据库只追加新迁移，不修改已冻结迁移。
4. ADR 决策变化新增 ADR，并将旧 ADR 标记为 Superseded。
5. Judge、指标、资格规则、模板和协议均使用独立运行时版本，不以文档版本替代。
6. V1.0 软件发布仍须满足 SPEC-10 的全部 Go/No-Go 门禁。
