## 审计对比

- 新增 `GET /audits/{auditId}/comparison?baseAuditId=`：
  - 校验两次审计属于同一项目；
  - 返回 7 类指标的 base/target/delta、分子分母；
  - 返回计划/完成/有效样本数。
- 指标取各自最新可用快照（含人工回写版本）。
- 审计详情页新增“与上次审计对比”表，展示核心指标与样本变化。
- 契约新增 1 个路径，共 87 Path。

## 边界

- 仅整体指标，不支持按引擎/问题/竞品切片；
- 不做统计显著性检验；
- 不比较 Findings 明细（Finding 未直接绑定 audit）；
- 无任意两次审计选择器，UI 默认对比上一次。
