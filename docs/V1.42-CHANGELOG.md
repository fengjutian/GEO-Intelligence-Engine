# GEO Intelligence P0 V1.42 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.41，待项目负责人确认

## 成员与权限页面

- 新增“成员设置”页面：
  - 读取 `/api/v1/me` 获取当前租户；
  - 成员列表展示邮箱、OIDC subject、角色与状态；
  - 角色下拉直接调用 `PATCH /tenants/{id}/members/{memberId}`；
  - 邀请表单调用 `POST /tenants/{id}/invitations`，一次性展示 Token；
  - 最后 Owner 保护等错误直接展示。
- 菜单新增“成员设置”，复用既有 RBAC 与租户隔离。
- 前端无新增后端接口。

## 边界

- 未提供停用/恢复成员按钮（API 已支持）；
- 无分页、搜索与项目级成员配置 UI；
- 无服务账号/API Token 管理；
- 邀请 Token 仍以明文一次性返回，未接邮件发送。
