# GEO Intelligence P0 V1.5 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.4，待项目负责人确认

## 变更

- 新增 `cmd/model-worker`：按 2 分钟租约领取审计样本，调用 Model Gateway，持久化 `ai_requests`、`ai_responses`、Usage、成本、延迟和原始响应哈希。
- 样本执行失败按一次重试后标记 failed；审计在采样耗尽后收敛为 `succeeded` / `partial_success` / `failed`。
- 迁移 `000008` 为 `audit_samples` 增加租约与尝试次数，为 `knowledge_snapshots` 增加冻结内容，执行时不再读取可变品牌配置。
- 开发脚本统一启停五个服务，Model Worker 健康检查 `:8083/healthz`；未配置供应商密钥时保持健康但不领取样本。
- 公开 API 契约无变化。
