# GEO Intelligence P0 V1.33 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.32，待项目负责人确认

## FEAT-10 第一阶段：内容结构质量

- 抓取 Completion 新增 `headings`（最多 50 条）与 `textSample`（前 2000 字符），供确定性内容规则使用。
- Go 内容规则（`content-rules-v1`）：
  - `CONTENT_HEADINGS_MISSING`：正文 ≥300 字但无任何语义标题；
  - `CONTENT_H1_MISSING`：有标题但无 H1；
  - `CONTENT_H1_MULTIPLE`：多个 H1；
  - `CONTENT_HEADING_SKIP`：标题层级跳跃；
  - `CONTENT_ANSWER_FIRST`：首句少于 40 字，缺少直接回答；
  - `CONTENT_NO_EVIDENCE`：出现百分比/年份/倍数等统计表述，但无外部链接。
- 内容 Finding 使用 `source_version=content-rules-v1`，进入现有 Findings 列表、报告发现与优化任务链路。
- 新增 3 个单元测试（结构、多个 H1/证据、正常页面）。

## 实测

- 注入无 H1、层级 2→4、短首句、含 50% 统计且无外链的页面；
- 生成 4 条 Finding：H1 缺失（high）、标题跳跃（medium）、Answer First（medium）、无证据（medium）；
- 证据：`.run/content-findings-verification.json`。

## 已知边界

- FAQ、术语解释、事实/观点边界、作者与发布日期规则未实现；
- Answer First 为长度启发式，后续需按页面类型模板化；
- 内容分析同步在抓取事务中执行，尚无独立 analysis run。
