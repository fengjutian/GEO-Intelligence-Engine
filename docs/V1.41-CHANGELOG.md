## 多复核人与冲突仲裁

- 标注规则调整：
  - `pending` 与 `reviewed` 均可继续由其他复核人标注；
  - 同一复核人重复标注 409；
  - 出现任一 `disagree` 即将队列项置为 `conflict`，否则 `reviewed`。
- 仲裁允许 `reviewed` 或 `conflict`，成功后置 `adjudicated`；重复仲裁 409。
- 队列项返回标注数、一致数、不一致数；`stats.byStatus` 增加 `conflict`。
- 复核页面新增状态筛选（待复核/已复核/冲突/已仲裁）、标注计数与冲突仲裁表单。

## 实测

- 复核人 A agree、复核人 B disagree → `conflict`；
- 标注数 2（agree 1 / disagree 1）；
- 仲裁采纳 A → `adjudicated`；
- 统计：decisions agree=2、disagree=1、agreementRate=0.667；
- 证据：`.run/review-conflict-verification.json`。
