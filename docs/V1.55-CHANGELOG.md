# GEO Intelligence P0 V1.55 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.54，待项目负责人确认

## embedding-v1 向量聚类接入点

- 新增 OpenAI-compatible Embeddings 客户端：
  - `GEO_EMBEDDING_BASE_URL`
  - `GEO_EMBEDDING_API_KEY`
  - `GEO_EMBEDDING_MODEL`
- 聚类算法新增 `embedding-v1`：
  - 批量调用 `/embeddings`；
  - cosine 相似度，阈值 0.8；
  - 未配置或请求失败时自动回退 `semantic-v2`，返回 warning。
- 问题空间算法选择新增“向量 v1”。
- 单元测试使用 httptest 覆盖请求格式、鉴权、向量数量与未配置错误。
- 契约重建接口 algorithm 枚举新增 embedding-v1。

## 实测

| 场景 | 结果 |
|---|---|
| 未配置 embedding | 回退 semantic-v2 + warning |
| 使用本地 fake embedding 服务 | 生效 embedding-v1，无 warning |
| 聚类数（fake 全同向量） | 2（1 个锁定簇 + 1 个新簇） |
| 单元测试 | embeddings client 通过 |
| 证据 | `.run/embedding-clustering-verification.json` |

## 边界

- 仓库默认未配置真实 embedding 供应商，生产需提供 OpenAI-compatible 端点；
- 未做向量缓存、分批上限与成本核算；
- 阈值 0.8 为初始值，未按模型调优；
- 回退是静默降级，仅通过 warning 提示。
