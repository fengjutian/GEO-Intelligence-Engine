- 使用千问AI平台 OpenAI-compatible Embeddings：
  - Base URL：`https://maas.qianwenaiapi.com/compatible-mode/v1`
  - 模型：`qwen3.7-text-embedding-flash`
  - 向量维度：1024
  - 客户端按每批 10 条请求。
- 真实请求返回 HTTP 200，两段测试文本消耗 47 tokens。
- 对测试项目重建聚类：
  - `semantic-v2`：21 个聚类；
  - `embedding-v1`：13 个聚类；
  - 响应 `algorithmVersion=embedding-v1`、无 warning；
  - 已锁定聚类保持 `jaccard-v1` 且不被重建覆盖。
- API Key 仅写入本地 `.env`（已 gitignore），未写入文档、提交或响应。
