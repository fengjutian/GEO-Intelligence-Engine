# GEO Intelligence P0 V1.80 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.79，待项目负责人确认

## 监测计划修改间隔

- 监测页每个计划新增间隔下拉：
  - 每小时 / 6 小时 / 每天 / 每周；
  - 调 `PATCH /monitoring-schedules/{id}`。
- 实测：60 → 120 → 60 分钟，API 均正确回写。

## 告警邮件 / Webhook

- 新增 `internal/notify`：
  - Webhook：JSON POST，2xx 视为成功；
  - Email：SMTP PlainAuth + `smtp.SendMail`。
- 配置：
  - `GEO_ALERT_WEBHOOK_URL`
  - `GEO_SMTP_HOST/PORT/USER/PASS/FROM/TO`
- 告警创建后同步投递，结果写入迁移 `000026` 的 `delivery_json`：
  - `{"webhook":"sent"}` / `{"email":"sent"}` / 失败原因。
- 审计创建失败与执行失败告警都走同一 `insertAlert`。

### 实测

- 本地 Webhook 接收器成功收到 `audit_execution_failed`；
- `delivery_json = {"webhook":"sent"}`；
- 邮件未实测（无 SMTP 环境）。

## 最近审计结果与趋势入口

监测页新增：

- 每个计划展示最近审计：
  - status / completed / eligible；
- “趋势”入口锚点到最近审计趋势面板；
- 趋势面板展示最近 5 次 mention / recommendation / eligible。

## 边界

- 邮件只支持 SMTP 明文/STARTTLS 由库默认行为决定，未做 TLS 强制；
- 投递为同步，失败无队列重试；
- Webhook 无签名/鉴权；
- 邮件未实际验收；
- 趋势面板只展示整体指标，不按实体。
