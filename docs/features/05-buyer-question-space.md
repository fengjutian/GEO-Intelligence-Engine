# FEAT-05：买家问题与问题空间

> 功能版本：V1.0｜产品版本：P0 V1.0｜状态：已批准  
> 层级：P0-C｜判定与排期见 [功能优先级规划](../FEATURE-PLAN.md)  
> 需求：QRY-001～QRY-003｜对齐：SPEC-01、03、09 V1.0

## 1. 功能目标

基于已确认的品牌知识生成具有业务语义的买家问题，支持人工维护、批量导入、去重、聚类和版本发布，为审计提供不可变问题集。

## 2. 问题属性

每个问题包含：原文、语言、主题、意图、漏斗阶段、目标受众、目标实体、品牌型/非品牌型、业务价值、权重、来源、状态和生成依据。

生命周期状态：`draft → reviewed → active → retired`；用途标签独立为 `benchmark`、`monitoring` 或两者兼有。发布版本后生成不可变快照。

## 3. 生成来源

- 品牌、产品、功能、行业、客户和场景组合。
- 用户手工输入。
- CSV 批量导入。
- 基于模板和 LLM 的建议生成。

自动生成必须返回使用的知识实体和模板/Prompt 版本；不得把生成问题视为真实搜索量证据。

## 4. 问题分类

- 品牌理解型：包含品牌名，用于知识准确性。
- 类目发现型：不含品牌，询问候选方案。
- 比较决策型：比较能力、价格或适用性。
- 场景型：围绕行业、角色和任务。
- 风险采购型：安全、部署、合规、支持和成本。

报告默认分层，禁止品牌型问题与非品牌发现问题不加区分地汇总。

## 5. 数据模型

- `question_sets`：逻辑问题集。
- `question_set_versions`：不可变发布版本、哈希和发布时间。
- `questions`：问题文本、属性、权重和来源。
- `question_relations`：父子、改写和相似关系。
- `query_clusters`、`cluster_members`：聚类和代表问题。
- `question_generation_runs`：输入知识快照、模型和生成版本。

## 6. API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/projects/{id}/question-generation-runs` | 生成建议问题 |
| GET/POST | `/api/v1/projects/{id}/questions` | 查询和新增 |
| PATCH | `/api/v1/questions/{id}` | 编辑属性和状态 |
| POST | `/api/v1/projects/{id}/questions:import` | CSV 导入预检/提交 |
| POST | `/api/v1/projects/{id}/question-clusters:rebuild` | 去重和聚类 |
| POST | `/api/v1/question-sets/{id}/versions` | 发布不可变版本 |

导入采用两阶段：上传/解析预览 → 用户确认提交；错误行不静默丢弃。

## 7. 实现细节

1. 精确去重使用语言感知的规范文本哈希；语义近重复通过向量/文本模型产生候选，不自动删除原问题。
2. 聚类算法和阈值版本化，保存相似度和代表问题选择依据。
3. 人工可移动问题、拆分/合并聚类和指定代表问题；重建聚类不覆盖人工锁定关系。
4. 生成前从知识快照读取实体，避免使用未确认或后续变化的信息。
5. 自动生成结果先进入 draft；必须由用户审核才能发布为监测问题。
6. 发布时计算问题集内容哈希，后续修改创建新版本。
7. 权重默认 1；业务加权需要显式配置，同时报告保留未加权视图。
8. CSV 使用 UTF-8，支持模板下载，限制行数、文本长度和公式注入。

## 8. UI

- 问题空间以表格、聚类和漏斗视图展示。
- 筛选语言、主题、意图、漏斗、类型、状态和来源。
- 生成向导先选择知识范围，再预览建议，用户勾选入库。
- 聚类详情显示代表问题、成员、相似度和人工锁定状态。
- 发布版本显示新增、修改、停用和权重变化 Diff。

## 9. 异常与边界

- 问题包含竞争品牌：允许并标记比较型，不自动归为目标品牌问题。
- 问题过长、包含敏感数据或不符合语言：预检失败或进入人工复核。
- 聚类服务失败：原问题不受影响，可稍后重跑。
- 运行中审计引用旧版本：禁止修改旧版本，只能发布新版本供下次使用。

## 10. 验收标准

- AC-01：系统能基于品牌、产品和场景生成问题，并保存语言、意图、漏斗、主题、实体和依据。
- AC-02：用户可新增、编辑、启停和批量导入问题，导入错误逐行显示。
- AC-03：精确重复被识别，近重复以候选形式呈现，原始问题不会被自动丢弃。
- AC-04：聚类显示代表问题、成员和相似度，用户可人工调整并锁定。
- AC-05：发布版本后内容只读，已启动审计始终使用启动时版本。
- AC-06：品牌型与非品牌问题在 UI 和指标维度中明确区分。
- AC-07：CSV 导入能阻止公式注入和超限内容。
