## 0.60 + 人工复核流程评估

- 0.60：Recall 0.943，但 FP 13，需要人工拆分约 13 个误合并簇；
- 0.75：Precision/Recall 均 0.887，FP 6，人工拆分负担减半；
- 0.60 相比 0.75 只多召回 3 对，却增加约 7 个误合并；
- 结论：**不采用 0.60 作为默认阈值**；维持 0.75 + 人工拆分/合并流程。

## 决策

- 默认阈值保持 **0.75**；
- 聚类后人工复核仍是必要环节，尤其对 0.60–0.75 的近似簇；
- 不为了 F1 下降而降低阈值。
