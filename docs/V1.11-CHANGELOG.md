# GEO Intelligence P0 V1.11 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.10，待项目负责人确认

## 变更

- 新增 `POST /api/v1/audits/{id}/reports`：从最新指标快照生成版本化报告，固定协议、Judge、指标与模板版本，写入 summary/scope/metrics/findings/limitations 五个章节快照。
- 新增 `GET /api/v1/reports/{id}` 与 `POST /reports/{id}:publish`，报告状态从 ready 发布为 published。
- 新增 CSV 导出 `POST /reports/{id}/exports`：写磁盘工件并登记 SHA-256、大小与对象路径；`GET /reports/{id}/artifacts/{artifactId}` 下载。
- CSV 使用 UTF-8 BOM、固定 9 列表头，并对 `= + - @` 开头的单元格做公式注入转义。
- PDF 导出当前返回 `422 EXPORT_FORMAT_UNSUPPORTED`，待接入固定模板渲染器。
- 迁移 `000010` 为 `report_sections` 增加内联 `content_json`；公开契约新增读取、发布与下载路径。
