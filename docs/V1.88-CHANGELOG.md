# GEO Intelligence P0 V1.88 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.87，待项目负责人确认

## 爬虫日志自动接入

- 新增 `POST /projects/{id}/bot-logs/text`：直接提交 Apache/Nginx combined 原始日志文本，服务端自动解析。
  - 解析 IP、时间、方法、路径、状态码、User-Agent；缺失 UA 与静态资源（css/js/图片/字体）自动跳过；
  - 单次最多 1000 行，返回 `inserted` / `skipped`；
  - 入库标记 `ingest_source='access_log'`，与手工 API 导入区分。
- 新增 `GET /projects/{id}/bot-logs/coverage?days=`：
  - `pages`：已抓取页面数；
  - `aiVisited`：AI 爬虫实际访问过的页面数；
  - `neverVisited`：**AI 从未抓取**的页面路径（最多 100 条）；
  - `robotsBlocked`：AI 爬虫被 401/403/429 拦截的次数；
  - `status`：200 段 / 403 段 / 404 段 / 5xx 段分布。

## 信源自动发现

- 新增 `POST /projects/{id}/source-mentions/discover`：提交 watchlist URL（≤20），服务端抓取并在正文中查找品牌名或别名。
  - 命中时提取页面标题与前后 160 字上下文作为摘要；
  - 未命中、抓取失败、非公开地址均计入 `skipped`；
  - 返回 `fetched` / `discovered` / `duplicates` / `skipped` / `errors`。
- 去重：URL 规范化（去 query、去尾斜杠、主机小写）+ 标题哈希，库内 `uq_mention_dedupe` 唯一约束兜底。
- 权威度评分（0–1）：
  - wikipedia 0.95；gov/edu 0.90；G2/Capterra/TrustRadius 0.85；
  - 科技媒体 0.75；知乎/Reddit/V2EX 0.55；Medium/Substack 0.45；
  - 品牌自有域名 0.40（避免自证主导信源图谱）；未知 0.50。
- 自动来源类型：≥0.85 → wiki，≥0.70 → media，≥0.50 → review，其余 other。

## 测试

- 日志解析：combined 行、静态资源过滤、缺 UA、状态分段；
- 发现：URL 规范化、标题参与哈希、权威度分层、品牌域名降权、摘要抽取（脚本内容不泄漏）、UTF-8 边界切片。

## 已知边界

- 日志接入为"提交文本"模式，未做文件 tail / 云日志订阅；如需常驻采集，建议由外部 agent 定期 POST。
- 覆盖分析按路径匹配，带 query 的差异会被归一；跨域名（CDN）未单独处理。
- 信源发现是 watchlist 扫描，不做搜索发现；单次 20 个 URL、不跟随站内链接、不解析 JS 渲染页面。
- 权威度为域名规则表，未接第三方权威度数据源。
