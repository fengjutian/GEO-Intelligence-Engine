# GEO Intelligence P0 V1.101 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.100，待项目负责人确认

## 发布版本历史与回滚恢复

文件系统连接器此前回滚只是**删除文件**，等于丢失上一版内容。现在改为保留并恢复：

- 迁移 `000036_publish_previous_content`：`publish_events` 增加 `previous_content`。
- 发布前读取目标文件现值，写入 `previous_content`；回滚时若有值则写回，没有才删除。
- 回滚事件记录 `restored previous content`，便于审计区分"恢复"与"删除"。

## 实测

| 步骤 | 结果 |
|---|---|
| 在目标路径预置标记文件 | `# previous version marker 2026-11-15` |
| 发布新草稿 | 文件被覆盖（`overwroteMarker=true`） |
| 回滚 | 文件恢复为标记内容（`restoredMarker=true`） |
| 事件摘要 | `restored previous content` |
| 证据 | `.run/geo-publish-restore-proof.json`、`.run/geo-publish-version-history.json` |

## 已知边界

- 只保留**上一版**，不支持回滚到更早版本（无版本列表）；
- `previous_content` 存在事件表里，大文件（如长 llms.txt）会放大表体积，未做截断或外置存储；
- webhook 连接器的回滚仍是"通知对端"，不涉及本地内容。
