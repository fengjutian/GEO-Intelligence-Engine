## 变更

- 新增 `ErrQuotaExceeded` 错误分类：MiniMax HTTP 429 且响应码 2056（Token Plan 用量上限）不再按普通 429 重试，直接标记为终态。
- Worker 将配额耗尽映射为 `PROVIDER_QUOTA_EXCEEDED`，样本失败尝试次数不再放大；审计按失败收敛。
- 回归脚本支持 `--provider` 与 `--model`，可选择真实供应商并指定模型，不再固定 deepseek-flash。
- 真实 MiniMax 接入结果：
  - 密钥通过 `/models` 健康检查；
  - Chat Completions 返回 HTTP 429、业务码 2056：账号 Token Plan 用量已达上限；
  - 两次真实审计均失败，样本错误码 `PROVIDER_QUOTA_EXCEEDED`，无成功调用、无指标；
  - 证据：`.run/minimax-regression-verification.json`。
- 结论：P0C-02 未完成，阻塞原因是 MiniMax 账号配额，不是代码或密钥格式。需充值/升级 Token Plan 或更换可用密钥后重跑。
- 安全提示：本次密钥曾在对话中明文出现，验证完成后应轮换。
