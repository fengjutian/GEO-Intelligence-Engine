# GEO Intelligence P0 V1.22 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.21，待项目负责人确认

## 变更

- 新增 `POST /api/v1/invitations/{token}:accept`：
  - Token 只以 SHA-256 比对；校验 pending、未过期；
  - 当前登录用户邮箱必须与邀请邮箱一致，否则 403；
  - 接受后创建或激活 membership，角色取邀请角色，邀请状态置 `accepted`，重复接受返回 409；
  - 写 `member.joined` 审计事件。
- 鉴权中间件允许“已认证但尚未成为成员”的用户访问邀请接受路径，其余资源仍要求 active membership。
- 项目级授权：新增 `projectAccess` 包装。Owner/ProjectAdmin 直接通过；其他角色若在租户内存在任意 `project_memberships`，则只能访问被授权项目，否则保持租户级访问（兼容存量）。已覆盖项目详情/编辑/归档、配置发布、品牌、别名、产品、竞品、抓取、问题集与协议读取。
- 契约新增邀请接受路径，共 52 Path。
- 已知边界：项目列表尚未按成员范围过滤，仍返回租户内全部项目。
