# GEO Intelligence P0 V1.81 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.80，待项目负责人确认

## 核心 GEO：问题编辑/状态与版本 Diff

### 问题编辑

- 新增 `PATCH /questions/{id}`：
  - 文本、意图、主题、漏斗阶段、类型、权重、状态；
  - 仅草稿版本可编辑；
  - 状态流转受控：draft → reviewed → active → retired；
  - 文本修改重新计算 hash、品牌型标记，并做重复校验；
  - 非草稿版本返回 409。

### 版本 Diff

- 新增 `GET /question-sets/{id}/versions/diff?from=&to=`：
  - 按规范化问题文本匹配；
  - 返回 added / removed / changed；
  - 变更包含状态、权重、类型差异。
- 当前测试项目没有多版本问题集，Diff 只完成代码路径，未做真实多版本验收。

### UI

- 问题空间新增“问题审核”折叠区：
  - 列出问题；
  - 状态下拉；
  - 直接 PATCH 状态。

## 边界

- 文本编辑 API 已支持，UI 暂只开放状态；
- reviewed/active 不能回退到 draft；
- 版本 Diff 按文本匹配，重命名会被视为 removed+added；
- 未在 UI 展示版本 Diff；
- 缺少多版本测试数据。
