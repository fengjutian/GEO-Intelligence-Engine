## FEAT-10 第二阶段：FAQ、作者与新鲜度

- 抓取元数据新增：`author`、`publishedAt`、`faq`（FAQPage 的 question/answer，最多 50 条）。
- 新增内容规则：
  - `CONTENT_AUTHOR_MISSING`（low）：无作者声明；
  - `CONTENT_PUBLISHED_DATE_MISSING`（low）：无发布日期；
  - `CONTENT_PUBLISHED_DATE_INVALID`（low）：发布日期无法解析；
  - `CONTENT_STALE_CONTENT`（medium）：发布日期超过 730 天；
  - `CONTENT_FAQ_ANSWER_MISSING`（high）：FAQ 问题无答案；
  - `CONTENT_FAQ_DUPLICATE`（medium）：FAQ 问题重复。
- 内容 Finding 仍写 `content-rules-v1`，进入 Findings/报告/任务链路。
- 新增 parser 与 Go 单元测试，覆盖元数据、FAQ、陈旧内容。

## 实测

注入 FAQPage（一个空答案、一个重复问题）与 2020 年发布日期，生成：

- `CONTENT_FAQ_ANSWER_MISSING` high
- `CONTENT_FAQ_DUPLICATE` medium
- `CONTENT_STALE_CONTENT` medium

证据：`.run/content-faq-verification.json`。
