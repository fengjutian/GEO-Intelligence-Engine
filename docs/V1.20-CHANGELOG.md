# GEO Intelligence P0 V1.20 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.19，待项目负责人确认

## 变更

- 新增 `GEO_AUTH_MODE=oidc`：RS256 JWT 校验，支持 issuer 发现、JWKS 拉取与 5 分钟缓存；校验签名、`iss`、`aud`、`exp`。
- JWT/OIDC 模式统一执行成员校验：按 `sub` 定位本地用户，查询 `memberships` 的 active 记录，并以数据库角色覆盖 Token 中的角色声明；非成员返回 403。
- 401/403 自动写入 `audit_logs`（action=`auth.denied`，含方法、路径、状态与 trace）。
- 新增 `GET /api/v1/me` 已在 V1.19 提供；OIDC 模式同样返回数据库角色。
- 新增配置：`GEO_OIDC_ISSUER`、`GEO_OIDC_AUDIENCE`、`GEO_OIDC_JWKS_URL`。
- 说明：仍未实现 Keycloak 登录页/Token 刷新；OIDC 校验已就绪，接入真实 Realm 时只需配置三个环境变量。
