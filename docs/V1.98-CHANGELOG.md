# GEO Intelligence P0 V1.98 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.97，待项目负责人确认

## 项目级告警（三类）

- 迁移 `000034_signal_alerts` 新增 `signal_alerts`（kind / severity / message / details / status）。
- 新增 `POST /projects/{id}/signal-alerts:evaluate` 触发检查，`GET /projects/{id}/signal-alerts` 列表，`PATCH /signal-alerts/{id}/resolve` 关闭。
- 三类规则：
  - `share_drop`：最新两次**同提示口径**审计的品牌份额下降 ≥ 15 个百分点；
  - `competitor_overtake`：任一竞品份额超过本品牌；
  - `crawler_silent`：项目有历史 AI 爬虫记录，但近 7 天为 0。
- 同类告警在未关闭前不重复创建；`share_drop` 只比较同 `promptTemplateVersion` 的审计，避免把口径变化当成份额下跌。

## 已知边界

- `competitor_overtake` 依赖最新快照里的 `share_of_voice` 明细，品牌份额为 0 且快照无明细时不会触发；

- 阈值（15pp、7 天）写死为常量，尚未做成项目级配置。
