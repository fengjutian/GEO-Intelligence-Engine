## 独立内容分析 Run

- 迁移 `000020`：`page_contents.content_json` 保存确定性内容快照（标题、正文样本、headings、author、publishedAt、FAQ、terms、links 等）。
- 新增 `POST /crawl-runs/{id}/content-analysis-runs`：
  - 基于快照重跑 `content-rules-v1`；
  - 旧 open 内容 Finding 标记 `superseded`，新规则结果重新写入；
  - 写入 `content_analysis_runs` 与 `content_signals`；
  - 同一 Run+版本幂等复用分析记录，并清理旧 signals。
- 新增 `GET /content-analysis-runs/{id}` 返回状态、页面数、信号数。
- 内容质量汇总只统计 `status='open'`，避免重跑后重复计数。
- 实体页面新增内容质量卡片：总数与高/中/低分布。
