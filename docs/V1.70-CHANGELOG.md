## Share of Voice 写入指标快照

- 指标生成新增：
  - `share_of_voice`：该实体出现的回答数 / 总回答数；
  - `mention_share`：该实体提及次数 / 总提及次数；
  - 维度：`entity` + `entityType`（brand / competitor）。
- 品牌与竞品统计逻辑与 Share of Voice API 一致；
- 人工指标重算 `metrics-v1h` 同样生成这些指标。
- 审计详情页指标标签补充“回答覆盖率”“提及份额”。

## 实测

审计 `01a1dda3…` 重算：

| 项 | 结果 |
|---|---|
| 指标总数 | 22（16 核心 + 6 share） |
| share_of_voice | 品牌 0.5、DeepSeek 1.0、OpenAI 0 |
| mention_share | 品牌 0.333、DeepSeek 0.667、OpenAI 0 |
| 证据 | `.run/share-metrics-verification.json` |

## 边界

- 维度中的实体名直接使用品牌/竞品名称；
- 竞品仍无别名表；
- 子串匹配可能把品牌别名重复计数；
- 旧审计正文为空，重算后 share 指标为 0；
- 报告模板需要确认是否展示动态实体维度（当前指标数据已进入快照）。
