## FEAT-10 事实/观点边界与复核一致性

- 新增确定性规则 `CONTENT_OPINION_AS_FACT`（`content-rules-v2`）：
  - 句子同时含主观表达（推荐/值得/我们认为/arguably 等）与绝对结论（最好/第一/唯一/best 等）；
  - 且没有来源或归因（根据/数据显示/研究表明/according to 等）；
  - 严重度 medium，证据保留原句。
- 强化 `CONTENT_ABSOLUTE_CLAIM`：
  - 有外部链接或归因时保持 low；
  - 无来源时提升为 medium，并记录 `sourced:false`。
- `GET /projects/{id}/content-quality` 新增 `review`：
  - reviewed / confirmed / dismissed / acceptedRisk；
  - confirmRate、dismissRate；
  - `byRule` 同时给出 open/confirmed/dismissed/acceptedRisk。
- 实体页内容质量卡片展示已复核数与确认率。

## 边界

- 规则为确定性句式/词表判断，不调用 LLM 做事实核验；
- 不判断引用是否真正支持主张，仅判断是否存在来源/归因；
- 观点规则存在词表误报，需人工确认；
- 内容分析重跑对旧抓取运行可能因无快照而 422，需重新抓取后再分析。
