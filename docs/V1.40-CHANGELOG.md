# GEO Intelligence P0 V1.40 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.39，待项目负责人确认

## 复核分派、仲裁与统计

- 新增 `PATCH /review-queue/{id}`：分派给 active 租户成员，非成员 422。
- 新增 `POST /review-queue/{id}/adjudications`：仅 `reviewed` 可仲裁，写 `adjudications`，队列项置 `adjudicated`；重复仲裁 409。
- 新增 `GET /review-queue/stats`：
  - byStatus（pending/reviewed/adjudicated）；
  - byPriority；
  - decisions（agree/disagree/uncertain）；
  - agreementRate = agree / (agree + disagree)。
- 复核页面新增统计条：待复核、已复核、已仲裁、一致率。
- 契约新增 3 个路径，共 67 Path。
