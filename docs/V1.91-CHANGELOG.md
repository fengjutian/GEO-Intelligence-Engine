# GEO Intelligence P0 V1.91 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.90，待项目负责人确认

## 实验样本量规划

- 新增 `POST /api/v1/projects/{projectId}/experiments/plan`：
  - 入参 `baselineRate`、`mde`、`alpha`（默认 0.05）、`power`（默认 0.80）；
  - 返回每组样本量、总样本量、该样本量下的最小可检测效应，以及中文解释。
- 公式为两比例 z 检验的样本量公式：`n = (z_{1-α/2} + z_power)² · (p₁q₁ + p₂q₂) / MDE²`。
- 反向估算：给定每组 n，可反推能检出的最小绝对提升。

## 序贯检验

- 新增 O'Brien-Fleming alpha spending：`AdjustedAlpha(look, plannedLooks, alpha)`。
  - 最终 look 恰好花掉 0.05；
  - 早期 look 边界更严（3 次分析时第一次约 0.0007），避免"边看边测"导致的假阳性。
- `EvaluateAtLook` 在每次中期分析时给出 `stop / continue / insufficient_sample` 与调整后的阈值。

## 实测

| 设计 | 结果 |
|---|---|
| 基线 50%、检出 10 个百分点 | 每组 385，合计 770 |
| 基线 10%、检出 5 个百分点 | 每组 683，合计 1366 |
| 基线 20%、alpha=0.01、检出 5 个百分点 | 每组 1624，合计 3248 |
| 非法输入（MDE 使处理组超过 100%） | 422 `PLAN_INPUT_INVALID` |
| 证据 | `.run/experiment-plan-verification.json` |

## 测试

- 样本量与两比例公式一致（基线 10%、MDE 5% → 约 683）；
- 效应越小所需样本越多；
- 非法基线/MDE/alpha/power 一律报错；
- 反推 MDE 与正算一致（683 → 约 0.045）；
- alpha spending：最终 look = 0.05，早期 look 显著更小；
- `EvaluateAtLook`：弱信号继续、强信号停止、小样本 insufficient。

## 已知边界

- 规划接口只做计算，不持久化到实验记录；实验中心尚未保存"计划样本量"字段。
- 序贯检验已实现算法，但 `Evaluate` 目前仍是单次比较，未把多个 look 串成流程。
- 未考虑整群效应（同一问题多次采样相关性），按独立样本近似。
