# GEO Intelligence P0 V1.79 增量记录

> 状态：已记录｜日期：2026-11-15｜前置基线：V1.78，待项目负责人确认

## 持续监测 UI

新增“持续监测”页面：

- 项目选择；
- 已发布协议选择；
- 创建监测计划（每小时 / 6 小时 / 每天 / 每周）；
- 计划列表：
  - 协议版本、间隔；
  - 下次运行时间；
  - 启用/暂停；
  - 连续失败次数与最后错误；
  - 立即运行、删除。
- 告警列表：
  - kind、消息、时间；
  - 未解决数量；
  - 解决操作。
- 计划与告警每 15 秒自动刷新。

## 导航

侧边栏新增“持续监测”，页面 ID `monitoring`。

## 边界

- 不能从 UI 修改间隔（仅创建时选择）；
- 立即运行是同步创建审计，不等待执行；
- 告警只覆盖创建失败与执行 failed/cancelled；
- 无告警通知渠道（邮件/IM）；
- 未做权限细分，沿用 run_audit/edit_project。
