# GEO Intelligence P0 V1.12 增量记录

> 状态：已记录｜日期：2026-11-13｜前置基线：V1.11，待项目负责人确认

## 变更

- 新增 `apps/report-renderer`：React 静态 HTML 模板 + Playwright Chromium `page.pdf()`，A4、打印背景、页脚页码，模板版本 `report-html-v1`。
- 渲染器阻断所有网络请求、只读取报告 JSON；报告 HTML 全部转义，不执行用户内容。
- `POST /reports/{id}/exports` 的 `pdf` 从 422 改为实际生成；CSV/PDF 各自替换旧工件，保留另一格式。
- 工件登记 SHA-256、大小与 `renderer_metadata`（模板版本、Chromium 版本）；下载接口按扩展名返回 `application/pdf` / `text/csv`。
- 新增 `GEO_REPORT_RENDERER`（默认 `apps/report-renderer/render.mjs`）、`GEO_NODE_BINARY`、`GEO_CHROMIUM_PATH`；未显式配置时自动探测系统 Chrome/Edge/Chromium。
- 渲染失败返回 `500 PDF_RENDER_FAILED`，不影响已 ready 的报告数据。
