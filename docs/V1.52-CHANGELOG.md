## LLM 问题生成

- `POST /projects/{id}/question-generation-runs` 支持：
  - `mode=llm`：调用 Model Gateway（默认 DeepSeek）；
  - `mode=template`：保留模板生成；
  - 可选 `provider`、`model`。
- LLM 提示仅使用冻结知识快照（品牌、产品、竞品、实体），要求严格 JSON 数组。
- 解析容错：
  - 支持 ```json 代码块；
  - 中英文问题类型/漏斗阶段归一；
  - 去重、长度与类型校验。
- 生成结果写入 `question_generation_runs`，`generator_version=llm-v1`，问题属性记录 model、basis、run id。
- LLM 失败或输出不可解析时自动回退模板生成，并在响应返回 `warning`。
- 重复检测改为基于规范化文本（不再仅依赖 hash），兼容 NFKC 前后历史数据。
- 问题空间新增“LLM 生成”按钮，显示模式与回退原因。
- 契约 generation 请求新增 mode/provider/model。

## 边界

- 问题生成调用未计入审计预算账本；
- 单次生成最多 20 条，未做人工逐条勾选；
- 未接入 embedding；语义聚类仍是 `semantic-v2` 词表/IDF；
- LLM 输出质量依赖供应商，需人工审核后发布。
