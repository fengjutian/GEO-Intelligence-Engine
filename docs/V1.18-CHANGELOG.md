# GEO Intelligence P0 V1.18 增量记录

> 状态：已记录｜日期：2026-11-14｜前置基线：V1.17，待项目负责人确认

## 变更

- 新增 `PATCH /optimization-tasks/{id}`：编辑标题、描述、优先级、负责人和截止时间，使用 `If-Match` 版本乐观锁，变更写入 `updated` 事件（含变更前后值）。
- 负责人以 UUID 保存并按 `BIN_TO_UUID` 返回，避免原始二进制泄露；截止时间使用 RFC3339。
- 任务看板新增字段编辑表单（优先级、负责人 UUID、截止时间），保存后刷新任务与事件。
- 修复任务详情中 assignee 原始二进制被当作字符串返回的问题。
- 契约在既有任务详情路径下补充 PATCH；无数据库迁移。
