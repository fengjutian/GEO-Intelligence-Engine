## 变更

- 新增只读接口 `GET /api/v1/crawl-runs/{id}/robots` 与 `GET /api/v1/crawl-runs/{id}/sitemaps`，用于查看抓取实际采用的 robots.txt 快照和 Sitemap 解析证据。
- 管理端抓取证据弹窗展示 robots 分组规则、原始内容、Sitemap 文档状态与解析错误。
- 数据库新增 `robots_snapshots`、`crawl_sitemaps` 表（迁移 `000006`），仅追加，不修改 V1.0 已冻结结构。
- 既有请求/响应语义不变；`CrawlRun.counts` 新增只读字段 `blocked`。
