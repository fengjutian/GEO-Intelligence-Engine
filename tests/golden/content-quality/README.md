# 内容质量黄金测试集

> 数据集版本：V1.0｜状态：已批准｜目标规模：不少于 240 页

## 1. 目的

评估 FEAT-10 的标题结构、Answer First、FAQ、术语解释、事实/观点边界、新鲜度和证据质量规则，避免未经校准的语义 Finding 直接进入高优先级报告。

## 2. 数据分层

| 维度 | 最低数量 |
|---|---:|
| 中文/英文 | 各 100 页 |
| 其他语言或混合语言 | 40 页 |
| 首页、产品页、文档页、博客、案例、FAQ | 每类 30 页 |
| 静态/JS 渲染 | 各 80 页 |
| 正例/负例/边界例 | 每条核心规则各不少于 20 个 |

同一网站模板不得跨训练与锁定测试集。划分为 development 50%、validation 25%、locked_test 25%。锁定集标签仅由质量负责人发布。

## 3. 标签

每条记录包含页面类型、语言、HTML Fixture、规则标签、证据 locator、严重度、标注者和仲裁结果。规则标签：`present`、`absent`、`not_applicable`、`uncertain`。

## 4. 标注流程

1. 标注指南培训和 20 页资格测试，Macro F1 ≥ 0.85。
2. Validation/Locked Test 100% 双人独立标注。
3. 分歧由高级标注者仲裁。
4. 页面正文、截图和来源许可保存哈希与记录。
5. 模板近重复先聚类，再按网站分组划分数据集。

## 5. 发布门槛

| 能力 | 指标 | 门槛 |
|---|---|---:|
| 标题/FAQ/作者/日期等确定性规则 | Precision | ≥ 0.95 |
| Answer First | Macro F1 | ≥ 0.85 |
| 术语解释 | Macro F1 | ≥ 0.80 |
| 事实/观点边界 | Macro F1 | ≥ 0.80 |
| 证据存在与可追踪 | Macro F1 | ≥ 0.85 |
| Finding 证据 locator | Exact/IoU 合格率 | ≥ 0.90 |

未达门槛的语义规则只能以“实验性/待复核”显示，不进入高优先级自动建议。每个语言和页面类型分层不得低于总体门槛 10 个百分点。

## 6. 文件

- `labels.schema.json`：记录结构。
- `seed.jsonl`：用于解析器和测试框架搭建的种子样本，不计入正式 240 页门槛。
- 正式 Fixture 存储在受许可的私有测试对象存储，仓库只保存脱敏 HTML 或对象引用与哈希。

## 7. 回归

分析器、规则、Prompt 或模型变化必须运行 Locked Test；输出按规则、语言、页面类型和渲染方式分层。低于门槛的版本不能发布为默认分析器。
